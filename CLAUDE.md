## Overview

Multi-machine NixOS configuration repository using flakes. Manages multiple hosts with shared modules and Home Manager for user configuration. Uses NixOS 25.11 with Home Manager release-25.11.

## Build Commands

```bash
# Rebuild and switch to new configuration (run on target host)
sudo nixos-rebuild switch --flake .#<hostname>

# Build without switching (test the build)
nixos-rebuild build --flake .#<hostname>

# Check flake for errors
nix flake check

# Update flake inputs
nix flake update

# Fresh install to /mnt
sudo nixos-install --flake /mnt/etc/nixos#<hostname>
```

Hostnames defined in flake.nix: `lenovo-nixos`, `desktop-nixos`

## Architecture

```
flake.nix              # Main entry point - defines all host configurations
├── modules/           # Shared, reusable NixOS modules
│   ├── common.nix           # Boot, locale, user, nix settings
│   ├── gnome-desktop.nix    # GNOME, PipeWire, extensions, Firefox
│   ├── networking.nix       # NetworkManager, SSH, firewall, Tailscale
│   ├── packages.nix         # System-wide packages
│   └── virtualization.nix   # KVM, Podman, Distrobox
├── hosts/             # Host-specific configurations
│   └── <hostname>/
│       ├── default.nix              # Host-specific settings
│       └── hardware-configuration.nix  # Auto-generated by nixos-generate-config
└── home/
    └── dylan.nix      # Home Manager config (dconf, keybindings, dock favorites)
```

Each host in `flake.nix` composes modules from `modules/` plus its host-specific config from `hosts/<hostname>/`. Home Manager is integrated inline in the flake.

## Key Patterns

- **Module composition**: Hosts import shared modules (`./modules/common.nix`, etc.) and host-specific config (`./hosts/<hostname>`)
- **Home Manager**: Configured per-host in flake.nix, imports user config from `./home/dylan.nix`
- **NUR overlay**: Applied per-host for Firefox extensions via `nixpkgs.overlays = [ nur.overlays.default ]`
- **Hardware config**: Each host needs `hardware-configuration.nix` generated by `nixos-generate-config --root /mnt`

## Adding a New Host

1. Create `hosts/<hostname>/default.nix` with host-specific settings
2. Generate `hosts/<hostname>/hardware-configuration.nix` on the target machine
3. Add a new `nixosConfigurations.<hostname>` block in `flake.nix` composing the required modules
